ARK BUSTERS（KIDS・TEEN）利用規約

最終更新日：2026年10月14日

この利用規約（以下「本規約」）は、アーク総合学院合同会社（以下「当社」）が提供するスマートフォンアプリ「ARK BUSTERS KIDS」および「ARK BUSTERS TEEN」（以下「本アプリ」）の利用条件を定めるものです。本アプリをダウンロードまたは利用した時点で、本規約に同意したものとみなします。未成年の方は、保護者の同意を得たうえでご利用ください。

第1条（本アプリの内容）

  1. 本アプリは、英語および各教科の学習をゲーム形式で行うためのアプリです。
  2. 本アプリの一部の問題は無料で利用できます。すべての問題を利用するには、アプリ内課金による購入（買い切り）が必要です。
  3. 当社は、問題の追加・修正、機能の変更を予告なく行うことがあります。

第2条（アプリ内課金）

  1. アプリ内課金の決済は、Apple Inc.（App Store）またはGoogle LLC（Google Play）を通じて行われ、各ストアの規約が適用されます。
  2. 購入したコンテンツは、同じストアアカウントで同じアプリをインストールした端末で「購入を復元」することにより再度利用できます。
  3. 返金については、各ストアの返金ポリシーに従います。当社が直接返金を行うことはできません。
  4. KIDSとTEENは別々のアプリであり、購入は各アプリごとに必要です。
  5. 当社の塾生向けに配布するコード（オファーコード等）は、当社が指定した本人のみが利用できます。

第3条（学習用アカウント）

  1. 当社の塾生には、学習の進み具合を保存するための学習用IDを発行することがあります。
  2. 学習用IDとパスワードは本人（または保護者）が管理し、第三者に貸与・譲渡しないでください。
  3. パスワードを忘れた場合は、当社までご連絡ください。
  4. ログインしなくても本アプリは利用できます。学習用IDは有料コンテンツの解放には使用しません。

第4条（禁止事項）

利用者は、次の行為をしてはなりません。

  1. 本アプリの問題データ、画像、音声、プログラムを複製、改変、再配布、販売すること
  2. 本アプリの不正利用、リバースエンジニアリング、不正アクセス
  3. 他の利用者または当社に不利益・損害を与える行為
  4. 法令または公序良俗に反する行為

第5条（知的財産権）

本アプリに含まれる問題、キャラクター、イラスト、音声、プログラムその他一切のコンテンツの著作権等の知的財産権は、当社または正当な権利者に帰属します。

第6条（免責事項）

  1. 当社は、本アプリが利用者の特定の目的（試験の合格等）に適合することを保証しません。
  2. 端末の故障、通信環境、ストアの障害等により本アプリが利用できない場合、当社は責任を負いません。
  3. 当社の故意または重大な過失による場合を除き、本アプリの利用により生じた損害について、当社の責任は利用者が当社に支払った金額を上限とします。

第7条（サービスの変更・終了）

当社は、必要と判断した場合、利用者に事前に通知のうえ、本アプリの提供を変更または終了することがあります。

第8条（規約の変更）

当社は、必要に応じて本規約を変更することがあります。変更後の規約は、アプリ内または当社ウェブサイトに掲載した時点から効力を生じます。

第9条（準拠法・管轄）

本規約は日本法に準拠し、本アプリに関して紛争が生じた場合は、広島地方裁判所を第一審の専属的合意管轄裁判所とします。
