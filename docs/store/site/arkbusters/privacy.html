ARK BUSTERS（KIDS・TEEN）プライバシーポリシー

最終更新日：2026年10月14日

アーク総合学院合同会社（以下「当社」）は、当社が提供するスマートフォンアプリ「ARK BUSTERS KIDS」および「ARK BUSTERS TEEN」（以下「本アプリ」）における利用者の情報の取扱いについて、以下のとおり定めます。

1. 取得する情報

情報取得する場面利用目的
学習の進み具合（スコア、クリア状況、集めたカード、設定したニックネーム）アプリの利用中学習の記録を表示するため。ログインした場合は、機種変更時に進み具合を引き継ぐため
学習用ID（当社が塾生に発行する英数字のID）ログインした場合のみ塾生本人の進み具合を保存・引き継ぐため
購入状況（アプリ内課金を購入済みかどうか）アプリ内課金を利用した場合購入したコンテンツを利用できるようにするため、購入の復元のため
マイク音声（トークバスターの発音チェック機能）利用者がマイクのボタンを押している間のみ端末上で英語の発音を文字に変換し、正解判定を行うため。音声は端末の外に送信・保存しません

本アプリは、氏名・住所・電話番号・メールアドレス・位置情報を取得しません。また、広告配信や利用者の追跡（トラッキング）を目的とした情報の取得は行いません。

2. 情報の保存先と第三者提供

  • 学習の進み具合と購入状況は、原則として利用者の端末内に保存されます。
  • ログインした場合、学習の進み具合と学習用IDは、当社が利用するGoogle LLCのクラウドサービス「Firebase」（Firebase Authentication / Cloud Firestore）に保存されます。Googleのプライバシーポリシーは こちら をご確認ください。
  • アプリ内課金の決済は、Apple Inc.（App Store）またはGoogle LLC（Google Play）が行います。当社はクレジットカード情報等を取得しません。
  • 当社は、法令に基づく場合を除き、取得した情報を第三者に提供しません。

3. お子様の情報について

本アプリは小学生・中高生が利用することを想定しています。当社は、お子様から保護者の確認なしに個人情報を取得しません。アプリ内課金の画面は、保護者による確認（保護者ゲート）を通過した場合にのみ表示されます。

4. 情報の保存期間と削除

  • 端末内の情報は、アプリを削除すると消去されます。
  • クラウドに保存された学習用IDと進み具合は、利用者または保護者からの依頼により削除します。削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。通常、受付から14日以内に削除します。

5. 安全管理

当社は、取得した情報への不正アクセス、紛失、改ざん、漏えいを防ぐため、アクセス制限・通信の暗号化などの適切な措置を講じます。

6. 本ポリシーの変更

本ポリシーは、法令の改正やサービス内容の変更に応じて改定することがあります。重要な変更がある場合は、アプリ内または当社ウェブサイトでお知らせします。
